# The Hive Cafe Kiosk — v2.0.0

![The Hive Cafe kiosk menu](../screenshots/menu.png)

## What's new

- A redesigned touchscreen menu with polished category icons, clearer spacing, and a simple progress line that does not look like a button.
- Faster ordering: drinks with a temperature choice start iced, while guests can still select hot, size, sweetness, and quantity.
- Product details now show caffeine guidance and flag allergen information that has not yet been verified with the cafe.
- English and Filipino language choices, a larger-text option, and an idle reset for the next guest.
- Editable cart items, sold-out availability checks, saved order history, and a private staff screen for cash status and availability.
- A direct Windows executable: after extracting the release ZIP, launch `kiosk.exe` without opening Visual Studio.

## Payment status

Cash orders wait for payment at the counter. Card and e-wallet are demonstration flows; they do not charge guests or collect payment details. Receipts are local text copies, not official tax receipts.

## Install

No prebuilt Windows ZIP was published for this version. Build from source at tag `v2.0.0` and run `kiosk/bin/Release/kiosk.exe` on Windows with .NET Framework 4.7.2 or later installed. Keep `System.Data.SQLite.dll` and `kiosk.exe.config` beside the executable.
